# QuotaBar downloads

Official QuotaBar desktop releases from **Midna Labs**.

QuotaBar brings usage readings from your AI tools into the macOS menu bar and Windows system tray. Local monitoring is free. QuotaBar Pro adds optional cloud history and a browser dashboard; the paid service is currently in preview.

This repository contains reviewed desktop downloads, checksums and signed update metadata. License notices are included with the applications. The app verifies the update feed using its bundled public key, then verifies each downloaded update's size and SHA-256 digest. Older builds need one manual installation to move onto this public update channel.
